# Contributing

Thank you for helping other Voplica users. These guidelines cover posting in [Discussions](https://github.com/voplica/help/discussions), reporting bugs (fastest in the studio's [support form](https://voplica.com/support); [Issues](https://github.com/voplica/help/issues) take them too) and changing the files in this repository.

## Before you post

- Search the existing discussions: your question may already have an answer.
- Pick the category that fits (the [README](README.md) lists them).
- Keep to one topic per discussion.

## Writing

- Use a clear title.
- Say what you did, what you expected and what happened.
- Say where: which page of the studio, the API, or Voplica in Claude or ChatGPT (the MCP connector).
- Give your browser and device.
- Add your own run ID if a run is involved; never anyone else's.

## Reporting a bug

The fastest route is private: sign in to the studio and open a **Bug report** issue on the [Support page](https://voplica.com/support) — every account can. [GitHub Issues](https://github.com/voplica/help/issues) take bug reports too (public, and may be slower): search the existing issues first, then open one with the bug report form. Either way, include:

- the steps to reproduce;
- what you expected;
- what happened;
- your own run ID or item ID, if there is one.

Never include a password, an API key or any other token.

**Never open an issue or a discussion in this repository for a security vulnerability.** Report it privately, as [SECURITY.md](SECURITY.md) explains.

## Never post

- Passwords, API keys (they start with `pat_`) or any other token.
- Payment details.
- Anyone else's personal data or run IDs.
- **Explicit images or links to explicit material.** They are not allowed in this forum.
  A problem that involves such material goes to direct support in the studio ([voplica.com/support](https://voplica.com/support)): any account for a legal, security or bug matter; Base and Premium for everything else.

## Be kind

Everyone here follows our [Code of Conduct](CODE_OF_CONDUCT.md).

## Changing the files

Pull requests that fix a typo or make something clearer are welcome. The maintainers review every pull request. A contribution to the files is accepted under this repository's license ([LICENSE.md](LICENSE.md)).

## Moderation

Maintainers may edit, hide, lock, move or delete posts that break these rules or the Code of Conduct, and may block accounts that keep breaking them.
