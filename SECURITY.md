# Security policy

## Scope

- voplica.com and its subdomains: the studio, the API and the MCP connector (Voplica in Claude and ChatGPT).
- This repository.

## How to report a vulnerability

Report it privately. **Never open an issue or a discussion in this repository for a security vulnerability**, and never post one in a pull request.

- **Fastest**: sign in to [voplica.com](https://voplica.com), open the [Support page](https://voplica.com/support) and open an issue in the category **Security vulnerability**. Every account can, free plans included.
- **Email**: security@voplica.com (may be slower).
- **GitHub**: on this repository's **Security** tab, choose **Report a vulnerability** (may be slower). If the button is not there, use the studio or email.

## What to include

- The URL or API endpoint.
- The steps to reproduce.
- The impact: what an attacker could do.
- Your Voplica username.

Never include another user's data.

## Rules

- Test only with your own accounts.
- If you reach data that is not yours, stop and report it.
- No denial of service, spam, social engineering or physical attacks.
- Give us reasonable time to fix the problem before you disclose it.

## What happens next

We acknowledge your report, keep you updated, and credit you once the issue is fixed if you want to be credited.
