# Voplica Help

The community forum for [Voplica](https://voplica.com), the AI image, video and audio studio.

Ask questions, suggest ideas and share what you made in [GitHub Discussions](https://github.com/voplica/help/discussions). Bugs are fastest through the studio's [support form](https://voplica.com/support) (any account); [GitHub Issues](https://github.com/voplica/help/issues) take them too (public). Anyone can read and search Discussions and Issues; posting needs a free GitHub account.

## Ask or search

Go to [github.com/voplica/help/discussions](https://github.com/voplica/help/discussions) and search first. If nobody has asked yet, start a discussion in the category that fits:

- **Announcements**: news from the Voplica team. Only the team posts here.
- **Q&A**: "How do I…?" questions. The best answer can be marked as the answer.
- **Ideas**: feature requests and suggestions.
- **Show and tell**: share what you made with Voplica. No explicit material.
- **General**: everything else about Voplica.

**Bug reports**: the fastest route is a Bug report issue in the studio's [support form](https://voplica.com/support) — private, open to every account. [GitHub Issues](https://github.com/voplica/help/issues) take bug reports too (public, and may be slower): search the issues first, then open one with the bug report form. Discussions keep questions, ideas and everything else. Never open an issue or a discussion in this repository for a security vulnerability: see [SECURITY.md](SECURITY.md).

## How to ask well

- **Search first.** Your question may already have an answer.
- **One topic per discussion**, with a clear title: "Video render stops halfway" helps more than "Help!".
- **Say what you did, what you expected and what happened.**
- **Say where it happened**: which page of the studio, the API, or Voplica in Claude or ChatGPT (the MCP connector).
- **Give your browser and device.**
- **Add your own run ID** if a run is involved. The run cards in your generation history show it next to a # sign, with a button to copy it.
- **Screenshots are welcome**, as long as they show no explicit material and no one else's personal data.

## Never post

This forum is public: anyone can read what you post. Never post:

- passwords, API keys (they start with `pat_`) or any other token;
- payment details;
- anyone else's personal data, or anyone else's run IDs;
- explicit images, or links to explicit material.

## Private help

- **Direct support in the studio**, at [voplica.com/support](https://voplica.com/support): private, answered by the Voplica team. With a Base or Premium plan, any question about your account or a run. Without a plan, up to three open issues about billing, legal and DMCA notices, security vulnerabilities and bugs — everything else belongs in Discussions, above.
- **Billing questions**: direct support in the studio, open to every account. **Account questions** need a Base or Premium plan; without one, ask in Discussions.
- **Legal questions and DMCA notices**: a Legal and DMCA notices issue in the studio is the fastest route, open to every account. Email to legal@voplica.com works only with the notice form in [DMCA.md](DMCA.md) completed and signed.
- **Security vulnerabilities**: never in public, so never in an issue or a discussion. A Security vulnerability issue in the studio is the fastest route; [SECURITY.md](SECURITY.md) lists the private routes.
- **Bugs**: a Bug report issue in the studio (fastest, private), or [GitHub Issues](https://github.com/voplica/help/issues) (public).

## Who answers

Other Voplica users, and the Voplica team when it can. No response time is promised here; for official help, use the private channels above.
